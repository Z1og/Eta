# 写码前对齐规范

1. 确定项目根：从本轮将操作的文件路径向上查找包含 `.trellis/` 的目录（最多向上 8 级）。
   找不到则告知用户该项目尚未初始化 Trellis，可以说「初始化 trellis」创建；然后按用户原任务继续。
2. 列出 `.trellis/spec/` 下所有 `*.md`，读取与本次任务相关的文件全文；
   编码任务至少读 `coding-style.md` 与 `project.md`。
3. 检查 `.trellis/tasks/` 是否有未完成的任务记录，有则读取并衔接。
4. 动手前用三五条向用户复述将要遵循的关键约定，不要长篇引用原文。
5. 按规范执行任务。规范与用户当轮指令冲突时，以用户指令为准，并明确指出冲突点。
